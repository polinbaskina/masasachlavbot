# Бот пожеланий для выпускного

## Как это работает

1. **Ты (админ) загружаешь список выпускников с их Telegram ID** через команду
   `/import_ids` — присылаешь боту пары «Имя, telegram_id», каждая с новой строки:

   ```
   /import_ids
   Иванов Иван, 123456789
   Петрова Мария, 987654321
   ```

   Бот сразу привязывает ID к имени в базе и присылает тебе архив `qr_codes.zip` —
   по одному PNG-файлу с QR-кодом на каждого выпускника (имя файла = имя человека).
   Эти QR можно печатать сразу, не дожидаясь, пока кто-то нажмёт `/start`.

2. **Каждый выпускник один раз лично пишет боту `/start`** (просто открывает бота
   и жмёт «Start»). Это единственный шаг, который нельзя убрать: Telegram не разрешает
   боту первым писать тому, кто ни разу не открывал с ним личный чат, даже если ID уже
   известен. Но вводить имя или переходить по особой ссылке не надо — бот узнает
   человека сразу по ID и пришлёт QR.

   Если у кого-то ID заранее нет — есть запасной вариант через персональные
   ссылки-активации (команда `/import` без ID, см. ниже).

3. **Бот сразу присылает выпускнику QR-код** со ссылкой на «гостевой» вход
   (`?start=g_...`). Этот QR можно распечатать или показать с телефона на выпускном.

4. **Гости сканируют QR** → бот спрашивает, подписаться именем или анонимно →
   гость пишет текст (можно с фото) → сообщение сразу улетает выпускнику в личку
   от бота, и одновременно сохраняется в базе.

5. Выпускник в любой момент может:
   - `/myqr` — получить свой QR ещё раз
   - `/letters` — перечитать все полученные пожелания одним списком (на случай,
     если сообщение потерялось в общем потоке чата)

## Админ-команды

Работают только для чатов, ID которых указаны в `ADMIN_CHAT_IDS`.

- `/import_ids` + список «Имя, telegram_id» (каждая пара с новой строки) — добавить
  выпускников сразу с известным ID
- `/import` + список имён без ID (каждое с новой строки) — запасной вариант, создаёт
  персональные ссылки-активации вместо прямой привязки по ID
- `/list_status` — кто уже нажал `/start` и распознан (✅/⬜️ по каждому имени)
- `/stats` — сколько выпускников, активаций и пожеланий всего

Свой Telegram chat_id можно узнать, написав что угодно боту
[@userinfobot](https://t.me/userinfobot).

## Установка (Railway)

1. Создай бота через [@BotFather](https://t.me/BotFather), получи токен и username.
2. Залей эту папку в GitHub-репозиторий.
3. На [railway.app](https://railway.app) → New Project → Deploy from GitHub repo.
4. В Variables добавь:
   - `BOT_TOKEN` — токен от BotFather
   - `BOT_USERNAME` — username бота без `@`
   - `ADMIN_CHAT_IDS` — твой Telegram ID (можно несколько через запятую)
5. Railway сам поставит зависимости из `requirements.txt` и запустит `Procfile`.

## Важные нюансы

- База — SQLite-файл `graduation.db` в рабочей папке. На Railway без подключённого
  volume файл может обнуляться при передеплое — если список большой и важный,
  добавь Railway Volume и примонтируй его в рабочую директорию, либо заранее
  протестируй и не передеплоивай во время мероприятия.
- Если сообщение не доставилось живьём (например, выпускник заблокировал бота),
  оно всё равно сохранено и появится в `/letters`, когда доступ восстановится.
- Обычный `/start` без персональной ссылки не регистрирует случайных людей —
  это специально, чтобы список выпускников не «замусорился» посторонними.
